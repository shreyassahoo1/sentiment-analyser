📘 Document Overview
🎯 What you will build
A web application where a user pastes a paragraph and receives:
An overall sentiment (Positive, Negative, or Neutral) with a confidence score
A sentence-by-sentence breakdown
A second opinion from a ready-made model (VADER) for comparison
A saved history of analyses in a database, with summary counts
🏆 Learning outcomes
By the end, you will be able to:
Explain how the layers of a full-stack application connect (React, Express, MongoDB).
Train a machine learning model and evaluate it.
Serve a trained model as an API (FastAPI).
Connect a Node.js backend to a Python ML microservice.
Test APIs with Thunder Client.
Inspect stored data with MongoDB Compass.
Explain how an AI/ML application’s backend works, including its limits.

🧠 The two ML concepts inside the pipeline
TF-IDF (Term Frequency, Inverse Document Frequency) turns a sentence into a list of numbers. A word’s number is high if it appears often in this sentence but rarely across all sentences, so distinctive words like “terrible” count more than common words like “the”. ngram_range=(1, 2) also tracks pairs of words like “not good”.
Logistic Regression is a classifier. It learns a weight for each word (e.g. “love” pushes toward positive, “awful” toward negative) and converts the total into a probability for each class. We use these probabilities as the confidence score.
Expected output: An accuracy value, a classification report (precision, recall, f1-score per class), three try-out predictions, and the message Model saved as model.joblib. A new file model.joblib appears in the folder.
⚠️ Honest note: With only 90 sentences, results are decent but not perfect, and accuracy may vary. Real systems train on thousands of examples.

Step 3.4: Turn the model into an API
📄 File: ml-service/app.py
import reimport joblibfrom fastapi import FastAPI, HTTPExceptionfrom pydantic import BaseModelfrom vaderSentiment.vaderSentiment import SentimentIntensityAnalyzerapp = FastAPI()model = joblib.load("model.joblib")      # our trained modelvader = SentimentIntensityAnalyzer()     # ready-made modelclass TextIn(BaseModel):    text: strdef classify(t):    probs = model.predict_proba([t])[0]    i = probs.argmax()    return str(model.classes_[i]), round(float(probs[i]), 3)@app.get("/health")def health():    return {"status": "ok"}@app.post("/predict")def predict(body: TextIn):    text = body.text.strip()    if not text:        raise HTTPException(status_code=400, detail="Text is empty")    # Overall result for the whole paragraph    overall, confidence = classify(text)    # Result for each sentence    parts = [s.strip() for s in re.split(r"(?<=[.!?])\s+", text) if s.strip()]    sentences = []    for s in parts:        label, conf = classify(s)        sentences.append({"text": s, "sentiment": label, "confidence": conf})    # Ready-made VADER model, for comparison    score = vader.polarity_scores(text)["compound"]   # -1 to +1    if score >= 0.05:        vader_label = "positive"    elif score <= -0.05:        vader_label = "negative"    else:        vader_label = "neutral"    return {        "overallSentiment": overall,        "confidence": confidence,        "sentences": sentences,        "vaderScore": score,        "vaderLabel": vader_label,    }

💡 Why a schema: MongoDB itself is flexible and accepts anything. The schema adds consistency and validation so our data stays clean.
⚡ Impact: The fields mirror exactly what the Python service returns, so we can save the ML result with almost no conversion.

What it does: Any request from React starting with /api is forwarded to Express on port 5000.
💡 Why we do this: React runs on port 5173 and Express on 5000. Browsers block calls between different origins (the CORS policy). With the proxy, the browser believes it is talking only to port 5173, so no CORS problems occur, and our React code can use short URLs like /api/analyses.

⚠️ Limitations to discuss
Small dataset: 90 sentences is a teaching size. Unknown words get weak predictions.

Sentence splitting: Our simple rule can break on abbreviations like “Dr.”
